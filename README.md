## 🖥️ Tampilan Antarmuka & Perintah CLI

Terminal ini dirancang dengan tema konsol retro hijau-hitam. Pengguna dapat mengetikkan perintah untuk mengakses informasi yang tersimpan di dalam arsip database.

### 📜 Daftar Perintah Utama (`start`)

Ketik perintah `start` di dalam terminal untuk menampilkan menu bantuan:

| Perintah | Fungsi / Deskripsi |
| :--- | :--- |
| `synopsis` | Menampilkan sinopsis lengkap dari cerita. |
| `list-chars` | Menampilkan daftar seluruh file rahasia karakter yang bisa diakses. |
| `open [nama]` | Membuka detail & berkas rahasia karakter tertentu (Contoh: `open rachel`). |
| `clear` | Membersihkan tampilan layar terminal. |
